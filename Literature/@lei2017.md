# A Novel Hybrid-Copy Algorithm for Live Migration of Virtual Machine

## TLDR

%% One-sentence summary of the core/claim contribution. %%

Pre- and post-copy algorithms are combined into hybrid-copy. For write-intensive workloads, doing a single copy of memory pages in advance might be enough, for read-intensive workloads on the other hand, multiple copy rounds can reduce page faults. The paper uses a Markov model to forecast the memory access pattern. Experiments show that the mechanism has good performance on both read- and write-intensive workloads.

%% Notes about the paper. %%

- Cloud: NAS for sharing VM between hosts -> shared memory concept in LEO?
- Goal of hybrid-copy: reduce number of post-copy page faults while maintaining migration time
- Novel hybrid-copy:
	- Forecast memory write pattern at each round of pre-copy
		- Only transmit half of dirty pages least likely to be modified are transferred -> to avoid duplicate transmissions
		- After each round, calculate SDF value to determine when to stop the iteration phase
	- During post-copy Markov model forecasts the memory access pattern to push remaining dirty memory pages

Basically, adjustable hyperparameter for determining when to stop the iterative pre-copy transfers to tweak efficiency between read- and write-intensive workloads.
