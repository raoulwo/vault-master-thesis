# Optimal Container Migration for Mobile Edge Computing: Algorithm, System Design and Implementation

## TLDR

%% One-sentence summary of the core/claim contribution. %%

Paper presents zero-downtime migration based on state duplication and state reproduction techniques.

%% Notes about the paper. %%

## Contributions

- Three live migration strategies of stateful containers are proposed

## Proposed Stateful Live Migration

Assumptions:

- Edge server co-located with access point
- When migration is triggered from SRC to DST edge servers
	- Widely-available docker images are assumed to be pre-cached on DST
	 - Can't be assumed using custom images

Concept:

- DST will be synchronized with DST, eventually same persistent state
- Two methods:
	- State duplication
		- SRC copies state and transfers to DST
	- State reproduction
		- SRC transfers instruction trace to DST so that it can reproduce a container
			- That's the idea of replay right?
- Migration utilizes packet relay to achieve zero-downtime

### Full-Copy Migration

- Naive state duplication used as baseline
- Complete image is created from SRC container and transferred to DST

NOTE: Problem with data transmission because of limited bandwidth.

### Differential-Copy Migration

- Not complete image is transferred, only writable layers to reduce data transmitted
	- Assumes common base image to be cached on DST

NOTE: Helps against high data transmission.

### Log-Replay Migration

- DST doesn't receive state from SRC, it instead collects the command trace from SRC
- Using the trace, it recreates the container from scratch

NOTE: As paper focuses on zero-downtime migration, don't know about migration time performance of this approach. Could be too high for connection window of LEO satellites.

NOTE: Also, how expensive in terms of memory is it to store command traces on satellites? What if we have a lot of concurrent migrations going on, what if we build a lot of container images at once?

NOTE: Again, the question arises if replay is deterministic in space: Gemini says it's not, GPT says otherwise so I won't follow this thread I think.
