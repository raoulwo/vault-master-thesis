# Live Migration of Video Analytics Applications in Edge Computing

## TLDR

%% One-sentence summary of the core/claim contribution. %%

Existing live migration strategies don't work for video analytics because of unique memory characteristics of video analytics applications. The authors propose three techniques to migrate state (warm-up, sync, replay), implement a prototype system and evaluate it using experiments. The results show that the application interruption (i.e. downtime?) is less than 405ms.

%% Notes about the paper. %%

Three existing migration types:

- Checkpoint/restore (e.g. CRIU)
- Pre-copy
- Post-copy

- Checkpoint/restore not suitable for VA applications due to huge memory sizes
- Pre-copy infeasible because dirty page rate in VA applications very high
- Post-copy not suitable because longer migration time since VA applications are delay-critical

Idea:

- *sync*: transfer persistent and frequently modified states (crucial states)
	- only need to transfer *crucial states* which make up <1% of base snapshot
- *warm-up*: preemptively fetch persistent and unmodified states (persistent states)
- *replay*: recompute volatile and frequently modified states (ephemeral states)
	- argument for replay -> re-analyzing video frames is more efficient than transmitting the memory state

Two problems:

- Compatibility with existing edge platforms
- Transparency of migration

Contributions:

- Analyze memory states of VA applications, show that existing migration solutions are insufficient
- Propose three memory states that should be treated differently: sync, warm-up, replay
- Implement and evaluate prototype

VA requirements:

- VA applications require analysis latency in hundreds of ms -> therefore minimal downtime
- VA application migration must ensure that all video frames are analyzed -> in order to be application-agnostic

Three phases of VA container migration:

- warm-up phase
- sync phase
	- *problem*: edge applications don't know about memory addresses to be transferred
- replay phase
	- *problem*: edge applications don't know which video frames to replay
